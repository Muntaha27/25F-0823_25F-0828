OOP Chess Game (C++)

A console-based Chess game developed using Object-Oriented Programming (OOP) principles in C++. This project was created as part of an academic assignment to demonstrate structured programming, class design, and game logic implementation in C++.

Overview

This project is a basic implementation of a Chess game in C++. It focuses on applying OOP concepts to model game components such as the board, pieces, and gameplay flow. The game is designed for two players and runs entirely in the console.

Features
8×8 chess board representation
Two-player turn-based gameplay
Basic move input system
Rule-based move handling 
Console-based interface
Continuous game loop until game ends
OOP Concepts Used
Encapsulation → Data and functions grouped within classes
Inheritance → Common behavior shared through base classes (if used)
Polymorphism → Flexible behavior through function overriding (if used)
Abstraction → Separation of game logic into manageable components
How to Play
The game is designed for two players
Players take turns entering moves in console input

The game processes moves and updates the board accordingly
